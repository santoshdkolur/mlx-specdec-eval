# Speculative Decoding Mathematical & Theoretical Foundations

This document details the mathematical theory, probability bounds, performance models, and metrics calculated by `spec-bench`.

---

## 1. Speculative Decoding Mechanics

Speculative Decoding addresses the memory-bandwidth bottleneck of auto-regressive LLM inference on Apple Silicon. Auto-regressive generation requires reading all model weights from Unified Memory for every single token generated.

### Algorithm Summary
1. **Draft Step:** A small, fast Draft Model ($M_D$) auto-regressively predicts $K$ candidate tokens $[x_1, x_2, \dots, x_K]$.
2. **Verification Step:** A large, high-quality Target Model ($M_T$) processes the prompt plus all $K$ candidate draft tokens in a **single parallel forward pass**.
3. **Rejection Sampling:** The probability distributions $P_T(x)$ and $P_D(x)$ are verified using rejection sampling to preserve exact sample distribution equivalence to $M_T$.

---

## 2. Rejection Sampling & Distribution Guarantee

For each draft token $x_i$ proposed by $M_D$, the verification step accepts $x_i$ with probability:

$$P_{\text{accept}}(x_i) = \min\left(1, \frac{P_T(x_i)}{P_D(x_i)}\right)$$

If token $x_i$ is rejected, all candidate tokens from position $i+1$ to $K$ are discarded, and a replacement token is drawn from the adjusted target probability distribution:

$$P_{\text{corrected}}(x) = \max\left(0, P_T(x) - P_D(x)\right)$$

### Output Identity Guarantee
- **Greedy Decoding ($T=0.0$):** Rejection sampling guarantees that the output generated by speculative decoding is **100% token-for-token identical** to running Target Model $M_T$ alone ($EM = 1.0$).
- **Stochastic Sampling ($T > 0.0$):** Rejection sampling guarantees that the output distribution is mathematically identical to $M_T$.

---

## 3. Mathematical Metrics

### A. Acceptance Rate ($\alpha$)

The acceptance rate $\alpha$ measures token alignment between $M_D$ and $M_T$:

$$\alpha = \frac{\sum_{i=1}^{N_{\text{steps}}} \text{AcceptedTokens}_i}{\sum_{i=1}^{N_{\text{steps}}} \text{DraftTokens}_i}$$

- $\alpha \to 1.0$: Draft model predicts target tokens with high accuracy.
- $\alpha \to 0.0$: Draft model predictions are consistently rejected.

---

### B. Expected Tokens Per Verification Step ($E[\text{Tokens}]$)

Given draft token count $K$ and acceptance rate $\alpha$, the expected number of accepted tokens per verification step is:

$$E[\text{Tokens}] = \frac{1 - \alpha^{K+1}}{1 - \alpha}$$

When $\alpha \to 1$, $E[\text{Tokens}] \to K + 1$.

---

### C. Tokens Per Second (TPS)

Generation throughput is calculated as:

$$\text{TPS} = \frac{N_{\text{total\_tokens}}}{T_{\text{wall\_clock}}}$$

---

### D. Speedup Factor ($S$)

The speedup ratio compares speculative generation throughput to baseline target generation:

$$S = \frac{\text{TPS}_{\text{speculative}}}{\text{TPS}_{\text{baseline}}}$$

- **$S > 1.0\times$**: Effective acceleration achieved.
- **$S = 1.0\times$**: Break-even point.
- **$S < 1.0\times$**: Overhead of running $M_D$ exceeds parallel verification gains.

---

### E. Task Domain Breakdown ($S_{\text{domain}}$)

Per-category metrics are evaluated dynamically across task domains $C \in \{\text{CODE}, \text{REASONING}, \text{CHAT}, \text{PROSE}\}$:

$$\alpha_{\text{domain}} = \frac{\sum_{j \in C} \text{AcceptedTokens}_j}{\sum_{j \in C} \text{DraftTokens}_j}$$

$$S_{\text{domain}} = \frac{\text{TPS}_{\text{speculative, domain}}}{\text{TPS}_{\text{baseline, domain}}}$$

---

## 4. Apple Silicon Unified Memory Tradeoff Equation

On Apple Silicon (M1/M2/M3/M4), GPU and CPU share Unified Memory. The memory bandwidth required per step is:

$$\text{Bandwidth}_{\text{speculative}} = \text{Size}(M_D) \times K + \text{Size}(M_T)$$

For speculative decoding to achieve speedup $S > 1.0\times$, the following inequality must hold:

$$\frac{\text{Size}(M_D)}{\text{Size}(M_T)} \times K + \frac{T_{\text{overhead}}}{T_{\text{target\_step}}} < \alpha \times K$$

`spec-bench` parameter sweeps identify the optimal $K$ value where speedup $S$ is maximized on a given Mac configuration.
